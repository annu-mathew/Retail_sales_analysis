Retail Sales Data Exploration & Analysis Dashboard

Project Overview

This project analyzes retail sales data using Python. The goal is to understand sales performance, product categories, customer demographics, and monthly revenue trends.

Objectives

- Explore and understand the retail sales dataset.
- Clean and prepare the data for analysis.
- Calculate key sales statistics.
- Analyze monthly revenue and product category performance.
- Visualize revenue by gender and age group.

Tools and Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

Dataset

The dataset contains retail transaction information, including:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

Analysis Performed

- Dataset exploration and summary statistics.
- Monthly revenue analysis.
- Revenue by product category.
- Revenue by gender.
- Revenue by age group.
- Total revenue, transactions, items sold, and customer count.

Visualizations

The project includes four charts:

1. Monthly Revenue Trend
2. Revenue by Product Category
3. Revenue by Gender
4. Revenue by Age Group

Output Files

- "retail_sales_cleaned.csv"
- "retail_sales_cleaned.xlsx"
- Chart images saved in the "visualizations" folder.

How to Run

1. Open the "notebooks" folder.
2. Open "retails_sales_analysis.ipynb".
3. Run the notebook cells from top to bottom.

Conclusion

This project demonstrates how Python can be used to explore retail data, calculate sales metrics, and visualize patterns that support business understanding.
