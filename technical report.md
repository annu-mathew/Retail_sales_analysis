Technical Report: Retail Sales Data Exploration & Analysis

1. Introduction

This project explores retail sales data using Python. The purpose is to understand sales performance, product categories, customer demographics, and monthly revenue patterns.

2. Project Objectives

- Explore the retail sales dataset.
- Check data quality and prepare the data for analysis.
- Calculate key sales statistics.
- Analyze monthly revenue.
- Compare revenue across product categories, gender, and age groups.
- Create charts to communicate findings.

3. Tools and Technologies

- Python: Programming language used for analysis.
- Pandas: Used to load, organize, and analyze the dataset.
- NumPy: Used for numerical operations.
- Matplotlib: Used to create charts.
- Jupyter Notebook: Used to write and run the analysis code.

4. Dataset Description

The dataset contains 1,000 retail transactions and nine original columns:

- Transaction ID
- Date
- Customer ID
- Gender
- Age
- Product Category
- Quantity
- Price per Unit
- Total Amount

5. Data Preparation

The dataset was loaded into Pandas for inspection. Data types, missing values, duplicate records, and numerical summaries were checked. The date column was converted to a date format for monthly analysis. A cleaned dataset was exported in CSV and Excel formats.

6. Analysis Performed

The following analyses were completed:

- Monthly revenue calculation.
- Revenue by product category.
- Revenue by gender.
- Revenue by customer age group.
- Total revenue, number of transactions, quantity sold, and customer count.

7. Visualizations

Four charts were created:

1. Monthly Revenue Trend — shows how revenue changes by month.
2. Revenue by Product Category — compares revenue from Beauty, Clothing, and Electronics.
3. Revenue by Gender — compares revenue for male and female customers.
4. Revenue by Age Group — compares revenue across customer age groups.

The charts were saved as PNG images in the "visualizations" folder.

8. Output Files

- "retail_sales_cleaned.csv"
- "retail_sales_cleaned.xlsx"
- PNG chart images in the "visualizations" folder
- "README.md"

9. Conclusion

This project demonstrates the use of Python for retail sales exploration, data preparation, statistical summaries, and visualization. The analysis provides a structured way to examine sales performance and customer purchasing patterns.
